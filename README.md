# 时境 SHIJING

## Vercel 免登录网页体验版

仓库根目录已配置 `vercel.json`，Vercel 默认部署 `preview/` 中的独立 React / Vite 静态体验版。保留红金白手机 UI、所有图片、主题详情、完整步骤、配乐播放器、日历、收藏、提醒和练习记录。全部内容开放浏览，无需会员登录、数据库、API 密钥或环境变量。点数为展示数据，不会扣点。

收藏、提醒和练习记录只保存在当前浏览器，不会上传服务器。可在会员信息弹层点击「重置体验记录」。示范活动日期会以访问当天为基准排在未来几天，历史导师图示保留原日期；所有示范吉时和方位均未经过正式核定。浏览器通知需要保持页面打开，也可下载 ICS 到系统日历。

### Vercel 部署

- GitHub 仓库：`ronfatt/qimenai`；分支：`main`。
- Root Directory：仓库根目录（留空），不要填 `app` 或 `preview`。
- Framework Preset：`Vite`。
- Install Command：`npm --prefix preview ci --include=dev`。
- Build Command：`npm --prefix preview run build`。
- Output Directory：`preview/dist`。
- Node.js：22.x 或更新的受支持版本。

这些设置已经写入根目录的 `vercel.json`。若原 Vercel 项目有手动覆盖设置，清除旧设置后重新部署最新的 `main`。无需迁移正式会员后端。

本地预览：`npm --prefix preview ci`，然后 `npm --prefix preview run dev`。生产构建：`npm --prefix preview run build`，本地检查产物：`npm --prefix preview run preview`。

## 原 Sites 会员版本

下面的说明适用于原有 Sites / Cloudflare 服务端版本，其登录、D1 和 R2 代码保留在仓库中。Vercel 网页体验版不导入或运行这些后端模块。

手机优先的导师内容会员平台，使用 React / Vinext、Cloudflare D1 和 R2。

## 已实现

- 中文会员首页、五类主题浏览、搜索、吉时月历、收藏和个人练习记录。
- 120初始体验积分、30天体验期、完整内容包解锁、服务器扣点流水；重复解锁不再扣点，余额不足及会员过期时禁止新解锁。
- 内容介绍与受保护的详细步骤、位置/朝向/物件位置的独立字段、准备清单、图文原稿。
- 原创环境音乐、设备中文语音朗读、分步练习播放器、暂停/进度/音量、感受与下一步行动记录。

- 导师工作台：草稿、编辑、发布、日期/时间/方位、步骤、图片上传、R2音频上传、发布状态和所需点数。

## 当前版本边界

这是私有功能体验版本，不收取真实费用。正式月费、支付网关、支付成功回调、自动续费、每月积分发放及后台Web Push尚未接入。UI明确标注体验状态，不提供伪造的支付成功页面。

未来日期与方位是产品演示数据，不代表经过导师审核的奇门择时。用户上传的2026年10月历史图示保留为历史参考；过期内容停止新解锁。正式内容发布仍需导师审核。

通知页面需保持打开才能触发站内/浏览器提醒。离开页面请下载并导入ICS日历文件。布局练习完成后，可从练习记录下载保留期结束的日历提醒。

当前图片作为内容数据保存，音频通过受保护的服务器接口从R2播放。上线真实收费前，应将私有图文统一迁移到受保护的对象存储、接入正式支付和权益事件、补充退款及服务条款并完成多用户和设备端测试。

## 红金白手机 App UI

界面以白色为底、朱红为主色、香槟金点缀。所有屏幕共享最多480px的App画布，手机自适应全宽。已移除桌面侧栏，通过底部导航进入首页、主题、日历、个人中心及导师工作台。首页包含红金主卡、会员点数条、圆形主题入口、近期吉时、双列内容及配乐卡。详情、提醒、会员和导师编辑使用底部弹层，播放器使用统一的红金色彩。主要样式文件为 `app/mobile-red.css`。


## 奇门九宫与基础逻辑

新增「奇门」底部导航、首页九宫入口和主题详情入口，支持 `/#qimen` 直接进入。九宫采用上南下北、左东右西的洛书排列：四九二／三五七／八一六。

- 完整教学盘固定为阳遁一局甲子时，显示八门、九星、八神、天地盘干、值符星、值使门与中宫寄坤说明，可切换图层并点选宫位查看解释。
- 地盘排布演示按用户选择的阴阳遁与1–9局，实际计算戊己庚辛壬癸丁丙乙的顺逆落宫。此模式只显示地盘，避免与固定示例的星门神混用。
- 基础逻辑包含九宫、三奇六仪、六甲遁仪、天地人神、节气定局的概念及五行生克，并链接古籍阅读。
- 未实现任意公历日期的完整起局、节气计算、不同定局流派、旺衰格局与自动择吉。教学盘不对应内容活动，也不自动生成导师仪式。

九宫规则和数据在 `app/qimen.ts`；界面与样式在 `app/components/Qimen.tsx`、`app/components/qimen.css`。
